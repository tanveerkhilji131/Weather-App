# Weather App

A responsive weather application built with React and TypeScript that fetches real-time weather data for any city.

### Features
- Search weather by city
- Real-time weather data
- Temperature, weather condition, humidity, and wind speed
- Loading state
- Error handling
- Empty input validation
- Responsive UI

### Tech Stack
- React
- TypeScript
- Axios
- OpenWeather API
- CSS

### Setup

```bash
npm install/i
npm run dev
